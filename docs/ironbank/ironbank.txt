IronBank Image Availability

An IronBank repository for MarkLogic Flux exists in Repo1 with tags starting from Flux 2.1.

The image:

Uses an IronBank-approved base image, aligned with MarkLogic Server’s IronBank image strategy.

Conforms to IronBank Dockerfile Requirements and passes IronBank’s hardening & vulnerability scanning pipeline.

Is digitally signed and approved in IronBank.

From a DoD-like environment, a user can:

Pull the image from IronBank.

Run a Flux command (e.g., ingestion list / ingestion run / embeddings operation)

Observe that the container executes the command and exits cleanly (no long-running process).

A CI/CD or job example is validated and documented where:

The pipeline spins up the Flux container.

Runs a real ingestion or embeddings command against a MarkLogic environment.

The job completes successfully and the container terminates automatically.
